# data/

Panelens inmatade data, en fil per flik. Skrivs av storage.py via GitHub
Contents API när du klickar 💾 Spara i panelen — varje sparning är en
commit, så historiken här visar exakt vad som ändrades och när.

Endast INMATNINGAR lagras. Poäng, status, marginaler och signaler räknas
vid rendering och ligger aldrig i filerna — samma princip som blå mot
svarta celler i Excel-arken de ersätter.

Redigera hellre i panelen än här: en handredigerad fil som inte går att
tolka som JSON gör att fliken vägrar ladda (med felmeddelande, inte tyst).
